# GlycoDesigner model runtime

This directory contains the minimal N-glycosylation reaction-network runtime required by the GlycoDesigner API. It is copied from the complete Fudan 2026 modeling work so this repository can be cloned and run independently.

For notebooks, generated network listings, references, and the full modeling record, see the [Fudan model repository](https://gitlab.igem.org/2026/software/fudan/model).
