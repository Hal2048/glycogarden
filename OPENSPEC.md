# OpenSpec development note

GlycoGarden was originally developed inside the Fudan team monorepo using an OpenSpec capability named `enzyme-compartment-distribution`.

The archived OpenSpec planning files are not runtime dependencies and are not copied into this standalone distribution. The implemented contract is documented in [README.md](README.md), exercised by `backend/tests/` and `frontend/tests/`, and described scientifically in [MODELING.md](MODELING.md).
